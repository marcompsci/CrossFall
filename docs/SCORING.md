# How Crossfall scores

Most crossword apps score one of two ways. NYT gives a gold star for a clean solve and a time, with no points. Arkadium gives points for squares you fill yourself plus a time bonus. Falling-block games score row clears, combos and hard drops. Crossfall uses all three and shows every line on the results screen, so nothing about the score is hidden.

## Points

| What | Points |
| --- | --- |
| Word | 50 + 10 per letter you typed yourself |
| Long word, no help | +25 per letter over 5 |
| Speed chain (next clue within 20 s of crossword time) | +50, +100, +150… capped at +250 a word |
| Hard drop | +2 per row the piece falls |
| Row clear | 100 / 300 / 500 / 800 for 1 / 2 / 3 / 4 rows |
| Back-to-back multi-row clears | ×1.5 |
| Clear combo (pieces in a row that each clear) | +50 per step |
| Target word on the middle line | +500 |
| Rush win | 150 + 3 per second left + 2 per second your timer has been shortened, +50 per consecutive rush win (max +250). Zen: flat 100 |
| Time bonus (win, at least half the letters typed by you) | 5 per second under 30 s a word |
| Hint (reveal a letter) | −25, and that letter scores 0 |

## Multipliers (applied to the total at the end)

| | |
| --- | --- |
| Gold solve: no hints, Check or Autocheck | ×1.2 |
| Fast fall speed | ×1.25 |
| Relaxed fall speed | ×0.9 |
| Zen mode | ×0.5 |

If the speed changes mid-game, the lowest multiplier used counts.

## Grade

Each puzzle has a par: every word solved with no help, the target, 300 per rush and half the possible time bonus. Your score divided by par gives the grade:

| Grade | Score vs par |
| --- | --- |
| SS | 160%+, gold solve and all 3 stars |
| S | 125%+ |
| A | 95%+ |
| B | 70%+ |
| C | 45%+ |
| D | below 45% |

## Leaderboards

- **Today:** your first try at the daily puzzle. Replays count as practice.
- **All time:** sum of every scored game.
- **This week:** best game this week on Game Center; on the web board, the week's total.
- **Best game:** single best score.

Custom puzzles and past dailies are practice: they show a score and grade but don't change the boards, your totals or your streak.
